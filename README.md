# مُجهّز بيانات الموظفين — Qoyod HR Import

أداة ويب تحوّل ملف موظفين من العميل **كما هو** (مخربط، ناقص، بأي شكل) إلى **قالب قيود HR الرسمي** جاهز للرفع.

**الموقع:** https://lzakaria-jpg.github.io/qoyod-hr-import/

> 🔒 كل المعالجة تتم داخل متصفحك. لا يوجد خادم، ولا يُرفع أي ملف أو بيانات لأي مكان.

## طريقة الاستخدام
1. من قيود: **الموظفين ← إضافة جماعية ← تنزيل القالب** (لنفس شركة العميل).
2. افتح الأداة وارفع القالب، ثم ملف العميل (xlsx / xls / csv).
3. راجع مطابقة الأعمدة (تلقائية).
4. صحّح بالمراجعة: التواريخ بالتقويم، القوائم بالاختيار، والأصفر بـ "تمت المراجعة".
5. نزّل ملف الرفع وارفعه على قيود.

## ماذا تفعل الأداة
- **تقرأ أي شكل:** عناوين عربي/إنجليزي/بدون عناوين، ترويسة بصفين، شيت لكل فرع، عناوين أقسام بين الصفوف، صفوف إجماليات وتواقيع، CSV بترميز Windows-1256.
- **تطابق الأعمدة** بالعنوان وبمحتوى القيم معًا (إيميل، آيبان، هوية، جوال، تواريخ، قوائم).
- **تنظّف القيم:** تواريخ هجري/ميلادي/أرقام عربية، جوالات بأي صيغة، رواتب بالعملة والفواصل، جنسيات بالصفة أو الرمز (EG, IN…)، حالات وأقسام بصيغ مختلفة.
- **ترجمة حرفية** عربي ⇄ إنجليزي للأسماء الناقصة (للمراجعة).
- **تكتشف الأخطاء:** هوية/إقامة (طول، خانة التحقق، التكرار)، بريد مكرر أو ناقص، تواريخ غير منطقية، آيبان (mod 97)، قيم غير موجودة بقوائم القالب.
- **ملف استكمال للعميل:** فقط الخانات الناقصة، ويُرفع بعد التعبئة لتنطبق تلقائيًا.

## التطوير
```bash
npm ci
npm run dev      # تشغيل محلي
npm test         # اختبار المسار كامل + دقة القراءة على 9 ملفات مخربطة
npm run build    # ملف HTML واحد في dist/
```
كل دفع (push) لفرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا على GitHub Pages.

> ملفات `test/` كلها بيانات وهمية للاختبار، والقالب فيها تجريبي (قوائمه ليست قوائم أي شركة).
